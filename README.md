# Customer Churn Prediction - Machine Learning Project

## Project Overview
This project predicts whether a customer will churn (leave the company) using Machine Learning. It helps businesses to take proactive steps to retain customers.

## Problem Statement
To analyze customer behavior and build a predictive model that identifies customers at risk of churning, so that the company can improve customer retention.

## Dataset Information
- Contains customer details like Tenure, Monthly Charges, Contract Type, Payment Method, etc.
- Target variable: `Churn` (Yes/No)

## What I Did?
- Data Cleaning & Preprocessing (Handled missing values, Encoding)
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Built Machine Learning Models (Logistic Regression, Random Forest)
- Evaluated model accuracy, precision, recall
- Visualized churn factors

## Files in this Repository
- `customer_churn.csv` / Notebook - Dataset and analysis
- `churn_prediction.ipynb` - Model building code (if available)
- `README.md` - Project documentation

## Tools & Technologies Used
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Scikit-Learn
- Jupyter Notebook / VS Code
- GitHub

## Key Insights Found
- Customers with Month-to-Month contracts have higher churn
- High Monthly Charges lead to more churn
- Tenure is inversely related to churn

## How to Run This Project
1. Clone this repository
2. Open the notebook in Jupyter / VS Code
3. Install required libraries: `pip install pandas scikit-learn`
